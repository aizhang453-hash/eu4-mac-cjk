欧陆风云4 苹果版中文插件 (eu4-mac-cjk) VERSION

让苹果电脑上的 Steam 版《欧陆风云4》能显示中文模组的中文。只支持游戏版本 1.37.5.0。

【安装】
1. 在 Steam 创意工坊订阅中文模组「Chinese Language Mod for 1.37」(想要更全的国名人名, 再订阅「Chinese Language Supplementary Mod for 1.37」)。
2. 找到「安装.command」:
   - 从 GitHub 下载的: 解压 zip 就看得到。
   - 从创意工坊订阅的: 在 Paradox 启动器的 Mod 列表里, 点这个 Mod 右边的「…」→「在文件夹中显示」。(这个 Mod 本身不用加进游戏套装。)
3. 先关掉游戏, 双击「安装.command」。
   如果提示「无法打开」或「无法验证开发者」: 打开 系统设置 → 隐私与安全性, 往下拉, 点「仍要打开」, 再双击一次。
4. 从 Steam 开游戏, 在 Paradox 启动器里把中文模组加进游戏套装, 开始游戏。

【卸载】双击「卸载.command」。(只在创意工坊取消订阅不会卸载, 要先双击它。)

【注意】
- Steam 更新游戏、或者「验证游戏文件完整性」以后, 插件会被冲掉, 再双击一次「安装.command」就行。
- 安装时会把原来的游戏程序备份成 eu4.原版备份, 卸载时换回来。
- 出问题看日志: ~/Library/Logs/eu4-mac-cjk.log

非官方项目, 跟 Paradox 和 EU4dll 的作者都没有关系。做法参考了 EU4dll (MIT 许可)。
